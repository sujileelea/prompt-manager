# 나만의 프롬프트 관리

- 이전 미션에서 쌓인 프롬프트(텍스트 지시문·이미지 키워드·페르소나·자동화)를 **한곳에서 분류·검색·즐겨찾기**하는 Python 콘솔 프로그램
- 외부 라이브러리 없이 Python 기본 문법(리스트·딕셔너리·조건문·반복문·함수)만 사용
- Codyssey AI_Application 미션1 산출물

## 실행 방법

- Python **3.10 이상**

```bash
git clone https://github.com/sujileelea/prompt-manager.git
cd prompt-manager
python3 main.py          # Windows: python main.py
```

- 메뉴 번호를 입력해 기능을 선택, 기능이 끝나면 Enter로 메뉴 복귀(화면 정리), `0`으로 종료
- 추가한 프롬프트와 즐겨찾기는 **실행 중에만 유지** (종료 시 초기화) — 보너스: 종료 시 `prompts.json` 저장을 물어보고, 다음 실행 시작 화면에서 불러오면 그대로 복원

## 기능 목록

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목 입력, 내용은 여러 줄 입력(빈 줄로 끝, 빈 값이면 재입력), 카테고리는 목록 선택 또는 직접 입력, 즐겨찾기 기본값 `False` |
| 2 | 프롬프트 목록 | 번호 · `[카테고리]` · 제목 · 즐겨찾기 ⭐ 표시, 총 개수 |
| 3 | 카테고리별 조회 | 카테고리 목록에서 선택 → 해당 프롬프트만 출력, 없으면 안내 |
| 4 | 프롬프트 검색 | 키워드가 제목 또는 내용에 포함된 프롬프트(대소문자 무시) |
| 5 | 프롬프트 상세 보기 | 제목·카테고리·즐겨찾기·조회수·내용 전체, 잘못된 번호 안내 |
| 6 | 즐겨찾기 추가 / 해제 | 번호 입력으로 즐겨찾기 토글 |
| 7 | 즐겨찾기 목록 | 즐겨찾기된 프롬프트만 모아 보기 |
| 8 | JSON 저장 / 불러오기 | [보너스 1] `prompts.json`으로 저장·복원. 시작 시 저장 파일이 있으면 불러올지, 종료 시 저장 안 한 변경이 있으면 저장할지 물음 |
| 9 | 카테고리별 Markdown 내보내기 | [보너스 1] `exports/<카테고리>.md` 생성 |
| 10 | 프롬프트 수정 | [보너스 2] 제목·내용·카테고리 수정 (Enter = 유지) |
| 11 | 프롬프트 삭제 | [보너스 2] 확인 후 삭제 |
| 12 | 조회수 TOP 목록 | [보너스 2] 상세 보기 횟수 기준 상위 5개 |
| 0 | 종료 | |

## 등록된 프롬프트 카테고리

| 카테고리 | 기본 등록 프롬프트 (이전 미션 출처) |
| --- | --- |
| 텍스트 생성 | 공고 정보추출 (JSON 구조화) — GenAI 미션1 · 뉴스 요약 편집자 — 팀 프로젝트 |
| 이미지 생성 | ORIGIN BLUE 터키석 원석 클로즈업 · ORIGIN BLUE 목걸이 착용 컷 — 멀티모달 미션2 |
| 영상 생성 | ORIGIN BLUE 착용 컷 영상 (Gemini/Flow) — 멀티모달 미션2 |
| 페르소나 | 공고 분석 도우미 페르소나 — GenAI 미션1 |
| 자동화 | Slack 링크 → AI News 분류·요약 (Gemini) — 노코드 자동화 미션3 · 뉴스 인사이트 분석기 — 팀 프로젝트 |
| 기타 | 뉴스 감성 분류기 — 팀 프로젝트 |

- 기본 데이터 9건 · 카테고리 6종. 추가 시 목록에 없는 카테고리를 직접 입력하면 새 카테고리로 등록

## 데이터 구조

```python
prompts = [
    {"title": "공고 분석 도우미 페르소나", "content": "당신은 '공고 분석 도우미'입니다...",
     "category": "페르소나", "favorite": True, "views": 0},
    ...
]
```

- `data.py`: 카테고리 목록(`CATEGORIES`)과 기본 프롬프트(`DEFAULT_PROMPTS`)
- `main.py`: 메뉴와 기능별 함수 — `show_menu()` `add_prompt()` `show_list()` `show_by_category()` `search_prompt()` `show_detail()` `toggle_favorite()` `show_favorites()` + 보너스 `save_to_json()` `load_from_json()` `export_markdown()` `edit_prompt()` `delete_prompt()` `show_top()`
